# @mvp/trade-prefs

Scaffolding package, not yet populated with real code. This is the future home
of the trade domain's user-preference APIs — watchlist, recent symbols,
layout, theme, and locale prefs currently under
`packages/storage/src/prefs/*` — once the Phase P1 re-layering migration moves
domain code out of the framework `@mvp/storage` package; see
[docs/ARCHITECTURE_REFACTOR_PLAN.md §2.2](../../docs/ARCHITECTURE_REFACTOR_PLAN.md#22-moves-mechanical-one-pr-behavior-preserving).
