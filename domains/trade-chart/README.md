of `packages/trade-client/src/chart.tsx` — the trade demo's self-contained
canvas 2D candle/depth chart adapter — which the plan classifies as demo-only,
not a generic framework capability, once the Phase P1 re-layering migration
splits `packages/trade-client` between the framework and domain layers; see
[docs/ARCHITECTURE_REFACTOR_PLAN.md §2.2](../../docs/ARCHITECTURE_REFACTOR_PLAN.md#22-moves-mechanical-one-pr-behavior-preserving).
