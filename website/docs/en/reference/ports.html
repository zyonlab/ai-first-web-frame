Allocation

Fragment ports start at 4201. register-fragment scans used ports and allocates the next free one unless --port is given, and refuses a port already taken by a compose service. The scaffolder does the same for the port it writes into a new server.ts.

PORT overrides the listen port at runtime for both the gateway and any fragment host.
