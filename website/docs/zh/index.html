ai-first-web-frame

一个 SSR 优先的微前端框架，两条立场贯穿始终：片段（fragment）是部署的最小单位，以及每一条边界都是机器可校验的契约。

一个页面不是一个构建产物，而是一组各自独立部署的 HTTP 服务的组合。每个服务自己拥有标记、数据、性能预算和发布通道。页面只负责声明槽位；框架在每一次请求时把槽位解析成具体的版本与地址，按依赖图执行，并在某一块失败时逐槽降级。
