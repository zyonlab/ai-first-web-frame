指南

实时订阅

一个不用 React 也能保持最新的服务端渲染面板：订阅数据源，把每一帧折叠成原地 DOM 补丁。片段声明自己听什么；页面只提供参数值。

为什么这么设计

第一版把这些全放在页面里：哪些片段是活的、每个需要哪个 source id、以及怎么给每个打 DOM 补丁 —— apps/page-trade/src/realtime.ts 里约 540 行。于是一个片段不改页面就无法变成实时的，也无法改变自己订阅什么。这直接违背了「片段是部署最小单位」这条主张。

1 · 在片段 manifest 里声明

// fragments/order-book/src/manifest.ts
dataDependencies: ["book.l2.<symbol>"],   // SSR 读一次
subscriptions:    ["book.l2.<symbol>"],   // 浏览器持续开着

这些是既有 <param> 词汇下的 source id 模板。GET /manifest 会发布它们，所以一个新版片段可以改变自己听什么，并独立出货。

没有占位符的模板（positions）是全局数据源。

2 · 片段提供一个 LivePanel

// fragments/order-book/src/live.ts
import type { LivePanel } from "@mvp/runtime/live";
import { orderBookManifest } from "./manifest";

export const orderBookLivePanel: LivePanel = {
  fragment: orderBookManifest.name,          // 对应 SSR 根节点的 data-fragment
  subscriptions: orderBookManifest.subscriptions,
  mount({ node, params, remounted }) {
    let prev = remounted ? null : ladderFromDom(node, params.symbol, depth);
    return {
      onFrame(_source, data) { /* diff 后原地打补丁 */ },
      stop() { /* 可选 */ },
    };
  },
};

在片段的 package.json 里以 ./live 导出。

3 · 页面只提供参数和一个 client

import { startLivePanels } from "@mvp/runtime/live";

const controller = startLivePanels({
  root,
  panels: TRADE_LIVE_PANELS,
  params: { symbol },
  subscribe: (source, onFrame) => client.subscribe(source, (e) => onFrame(e.data)),
  onParamsChange: (next) => { client = makeClient([next.symbol]); },
});

controller.setParams({ symbol: "ETH" });
controller.stop();

驱动从不接触数据 client，只看到解析后的 source id。

`remounted` 是最微妙的一点

参数变化时，所有面板都会被拆掉重挂（数据 client 是按 symbol 集合构造的，部分替换会让某些面板留在过期 client 上）。不一致的是 remounted：只有绑定了确实变化过的参数的面板才为 true。

这就是面板判断自己的 SSR DOM 是否还可信的依据：

面板订阅切换币对时
order-bookbook.l2.<symbol>remounted: true → 整梯重建；已渲染的行还是上一个币对的价格
trades-feedtrades.<symbol>remounted: true → 清空成交流
positions-tablepositionsremounted: false → 行保留；持仓是账户级的，不随界面上的币对变化

以前这条规则手写在页面里。现在它是从声明推导出来的。

降级

片段没有渲染、或渲染了降级内容（带 data-fallback）的面板会被跳过而不是挂载 —— 组合层已经判定那个槽位降级了，订阅不该把它复活。在 mount 或处理帧时抛错的面板经 onError 上报并被丢弃，页面其余部分照常存活。

辅助函数

templateParams(template) → 该模板绑定的参数名。

resolveSourceTemplate(template, params) → 具体 id；缺少被绑定的参数时抛错，而不是去订阅一个含字面量 <symbol>、永远收不到帧的 id。

补丁面板共用的 DOM 薄层：panelDocument、setFieldText、fieldText、parseFieldNumber、cssEscapeAttr。

让页面和片段保持诚实

apps/page-trade/src/liveContract.test.ts 会在以下情况让构建失败：某个面板声明的模板解析不出已知的 source id，或者它绑定了页面无法提供的参数 —— 后者会挂载一个静默地永远收不到帧的面板。
