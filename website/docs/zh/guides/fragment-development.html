开发片段

一个片段就是一个只干一件事的 Fastify 服务：给定 {props, ctx}，用 HTML 回答 POST /render。

目录结构

fragments/<name>/
  src/server.ts        @mvp/fragment-host 上约 20 行的适配器 —— 不要手写
  src/render.ts        渲染函数：{props, ctx} -> {html, assets, cache, metadata}
  src/manifest.ts      name/version/owner/renderMode/fallback/assets/budget/proxy/
                       dataDependencies/subscriptions
  src/budget.ts        本单元的性能预算
  src/data.ts          数据访问，经 @mvp/data / @mvp/request（绝不裸 fetch）
  src/styles.ts        随标记内联输出的作用域样式表
  src/island.tsx       可选的 React 岛屿
  src/live.ts          可选的非 React 实时面板
  tests/, Dockerfile, package.json, tsconfig.json, README.md, AGENT.md

HTTP 面由宿主拥有

@mvp/fragment-host 的 createFragmentServer 提供全部 8 个端点、Prometheus 指标和 trace 导出。你的 server.ts 只提供身份和渲染函数：

import { createFragmentServer } from "@mvp/fragment-host";
import { orderBookManifest } from "./manifest";
import { orderBookBudget } from "./budget";
import { renderOrderBook } from "./render";

export const SERVICE_NAME = "order-book";

export function buildServer(options = {}) {
  return createFragmentServer({
    serviceName: SERVICE_NAME,
    port: 4204,
    manifest: orderBookManifest,
    budget: orderBookBudget,
    render: renderOrderBook,
    ...options,
  });
}

这是被强制的，不只是建议：自建 Fastify 实例的片段会被 audit:deps 的 fragment-server-not-hosted 规则判失败。

render 收 (request, { trace, now })。如果输出里含时间，请从 now 取而不是 Date.now() —— 这是让渲染输出可测的原因，也是 market-header 的倒计时在测试下确定的原因。

降级是声明的，不是临场发挥的

manifest.fallback 是一段 HTML 字符串，在你的服务慢、报错或被跳过时由组合层替换上去。保持自描述，并带上同样的 data-fragment="<name>" 根节点加 data-fallback="true"：

fallback: '<section data-fragment="order-book" data-fallback="true">Order book unavailable</section>',

data-fallback 属性在运行时是有意义的，不只是视觉上的：实时面板驱动会跳过带此属性的节点，所以一个已降级的槽位不会被订阅「复活」。

数据访问

业务代码里不允许裸 fetch(...) —— audit:deps 的 raw-fetch-in-business-code 会判失败。用 @mvp/request（带超时和类型化错误的契约化 HTTP：RequestContractError、RequestPolicyError、RequestTimeoutError）或 @mvp/data（带缓存适配器、新鲜度校验和订阅的数据源注册表）。

另有一条 fetch-without-timeout，抓那种完全没有中止路径的 fetch。

声明你需要什么

两个独立字段，区别很重要：

// SSR 时读一次
dataDependencies: ["book.l2.<symbol>"],
// 浏览器面板持续开着
subscriptions: ["book.l2.<symbol>"],

order-form 展示了这种不对称：它在 render 时读 account，却不订阅任何东西。

样式

CSS 随标记以 <style data-fragment-style="<name>"> 内联输出，源在 src/styles.ts。audit:css 测量总字节、无用字节、重复规则、全局选择器和 !important 数量，并强制每个片段的 cssBytes 上限。源码中从未被引用的类名算作无用字节 —— 这就是为什么那些只在浏览器补丁代码里加类的片段要导出 *_CLASSES 常量，让引用可见。
