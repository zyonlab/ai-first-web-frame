分配规则

片段端口从 4201 起。register-fragment 扫描已用端口并分配下一个空闲值，除非给了 --port；已被 compose 服务占用的端口会被拒绝。脚手架在写新 server.ts 的端口时做同样的事。

PORT 在运行时覆盖监听端口，网关和任何片段宿主都适用。
