domain 示例 — domains/*

它们不是框架。存在的意义是展示「构建在框架之上的产品层长什么样」，同时给审计一些真实的东西去管。

包用途
@mvp/trade-contracts频道 id、载荷 schema、发布者/订阅者 ACL、订单流 reducer，以及 orderConstraints（tick/lot/杠杆档位校验，十进制安全算术）
@mvp/trade-dataC5 source id 注册表（sourceIds、parseSourceId、normalizeSymbol）、createTradeDataClient、确定性 mock 传输
@mvp/trade-prefs持久化的用户偏好
@mvp/trade-theme基于 @mvp/design-system 的交易作用域主题变量
@mvp/trade-chart图表渲染原语

发布

packages/* 除 @mvp/assets 和 @mvp/workers 外均为 private: false。apps/*、fragments/* 和 domains/* 都是私有。tools/create-component 是唯一可发布的工具。发布走 Changesets（pnpm changeset、pnpm version-packages、pnpm release）。
