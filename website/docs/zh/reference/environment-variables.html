Turborepo 的分类

turbo.json 刻意把它们分成两类，而 Biome 的 noUndeclaredEnvVars 会强制「代码读到的变量必须被声明」：

  • globalEnv —— 会改变任务行为的值，因此必须进缓存键：NODE_ENV、CI、MVP_DIAGNOSTICS、PUBLIC_SITE_ORIGIN、TRACE_SAMPLE_RATE、四个 SHELL_*、E2E_STRICT、DOCS_TEST_DEBUG、DOCS_TEST_KEEP_TMP。
  • globalPassThroughEnv —— 只用于寻址外部环境的值，因此绝不能进缓存键：SHELL_URL、PAGE_*_URL、*_URL、RECENTLY_VIEWED_COOKIE_SECRET。

这个分类是正确性问题，不是风格问题：把密钥放进 globalEnv，会让密钥轮换时缓存键跟着变；把行为开关放进 globalPassThroughEnv，则会让缓存返回一个过期的「通过」。

曾经声明但无人读取

REGISTRY_URL、REGISTRY_USERNAME、REGISTRY_PASSWORD 曾出现在 globalPassThroughEnv 里，而仓库里零处读取。它们暗示了一个并不存在的带鉴权的远程注册表集成，现已删除（F3）。
