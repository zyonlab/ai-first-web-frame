# shell-gateway

Independent Fastify gateway for route lookup, request context, safety headers, page proxying, and shell fallback.

Commands:

- `pnpm --filter @mvp/shell-gateway dev`
- `pnpm --filter @mvp/shell-gateway test`
- `pnpm --filter @mvp/shell-gateway build`
- `pnpm --filter @mvp/shell-gateway start`
